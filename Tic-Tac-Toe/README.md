# Tic-Tac-Toe 
### A simple Tic-Tac-Toe game built using  HTML, CSS and Javascript.

## Features Of Game
- Interactive UI
- Responsive design
- Two player game
- Restart game functionality
- Winner announcement

## Technologies Used
- HTML
- CSS
- Javascript

## How to run
1. Download the project
2. Open index.html in browser
